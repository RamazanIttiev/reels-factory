scalelab reels

scalelab reels is a personal publishing tool that creates short educational vertical videos about software engineering and publishes them to the creator's own TikTok and Instagram accounts (@scalelab.dev).

The tool uses the TikTok Content Posting API only to upload videos the owner has produced to the owner's own accounts. It does not read other users' data.
